Support

ReadFaster for Mac, version 1.0. Requires macOS 14 or later.

Need help or found a problem? Open an issue on GitHub and describe what happened. Issues are public, so please don't attach private documents.

Getting started

  • Open a PDF or text file with File › Open, or drop it onto the window.
  • Click any word to start reading from it, or double-click to start right away.
  • Press space to start. Words appear one at a time; keep your eyes on the red letter.
  • For a guided sample, choose Help › How ReadFaster Works.

Keys and gestures

space
Start, pause and resume. Pausing shows the line you're in.
↑ ↓
Faster or slower while reading. While paused, more or fewer lines around the word.
← →
Back or forward a sentence. While paused, one word at a time. Hold Shift for a sentence.
esc
Back to the page.
⌘ + / −
Bigger or smaller words.
Trackpad
Scrolling does what the arrow keys do. Pinch to resize the word. Click to pause.

Common questions

What speed should I start at?

Around 300 words a minute is comfortable for most people at first. Raise it a little at a time as it starts to feel easy, and slow down or pause for anything that deserves a closer look.

Which files can it open?

PDF, plain text, Markdown, RTF, Word (.docx) and HTML. You can also paste text with File › Paste Text to Read.

My PDF says it has no selectable text.

That PDF is a scan: a picture of the pages with no text in it. Run it through OCR first (Preview and Adobe Acrobat can both do this), then open it again.

The reading order looks wrong in one part of a PDF.

Complex layouts such as tables or text wrapping around figures can read out of order. Please open an issue with a description of the layout.

Can I make the PDF pages darker?

Yes. Use the half-circle button in the toolbar, or View › PDF Pages, to choose Original, Dimmed or Dark.

Where are my documents kept?

ReadFaster keeps a copy of each document in its own private storage on your Mac, so your library works even if the original file moves. Nothing is uploaded anywhere. To remove a document, right-click it in the library and choose Remove from Library.

Does it work offline?

Always. ReadFaster never connects to the internet. See the privacy policy.
